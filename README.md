# 🌐 My Portfolio

A personal portfolio website built with **React** to showcase my projects, skills, and experience.  
This portfolio serves as a central place for recruiters and collaborators to learn about me and easily get  in touch.

---

## 🚀 Live Demo
👉 https://sajidcraft.onrender.com/

---

## 🧩 Features
- Clean and modern UI
- Fully responsive design (mobile, tablet, desktop)
- Dedicated sections for:
  - About Me
  - Skills
  - Projects
  - Contact
- Resume view/download option
- Contact form powered by EmailJS (no backend required)
- Smooth navigation and user-friendly layout

---

## 🛠️ Tech Stack
- **Frontend:** React (Vite)
- **Styling:** Plain CSS (Flexbox & Grid)
- **Deployment:** Render
- **Email Service:** EmailJS
- **Version Control:** Git & GitHub
